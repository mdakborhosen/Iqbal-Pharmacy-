# OshudhBazar & PharmaPOS BD — ইকবাল ফার্মেসী

আধুনিক ফার্মেসি ম্যানেজমেন্ট, ওষুধের মূল্য যাচাই, ইনভেন্টরি স্টক ও ক্যাশ মেমো সিস্টেম।

- **লাইভ ডোমেইন:** https://iqbal-pharmacy.pages.dev
- **ভার্সন:** 2.5.0 (Updated: October 2026)
- **ফ্রেমওয়ার্ক:** Vite + React 19 + Tailwind CSS + PWA
- **ডাটাবেস:** Firebase Firestore + LocalStorage Dual-Sync

### প্রধান সুবিধাসমূহ
- বাংলাদেশের সকল কোম্পানির ২১,২৫০+ ওষুধের মূল্য ও জেনেরিক তুলনা
- দ্রুত বিক্রয় ইনভয়েস ও ডিপো ক্রয় চালান এন্ট্রি
- ডেন্টাল ও ফার্মাসিস্ট ডাক্তার কোয়ালিফিকেশন সিল সহ ক্যাশ মেমো
- দাম ছাড়া ডেলিভারি মেমো প্রিন্ট
- অফলাইন ও অনলাইন স্বয়ংক্রিয় সিঙ্ক
